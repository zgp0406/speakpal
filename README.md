# SpeakPal

SpeakPal 是“面向儿童英语发音的数字人口型与舌位可视化纠错系统”的 Android 原型项目。项目面向儿童英语发音学习中“错误难定位、纠错不直观、反馈不及时”的问题，计划通过语音评测、音素级错误诊断、数字人口型展示、舌位可视化反馈和个性化训练推荐，构建一套更直观的英语发音训练工具。

## 项目背景

传统英语发音训练主要依赖教师示范和学生模仿，儿童在学习过程中往往只能获得“读得像不像”或分数层面的反馈，难以理解具体是哪一个音素、哪一个口型或舌位动作出现了问题。

本项目参考计算机辅助发音训练（CAPT）、语音评测、数字人动画和人机交互等方向的研究思路，将发音评分从单词级结果扩展到音素级诊断，并通过数字人口型与舌位演示，把抽象的发音动作转化为儿童更容易理解的可视化反馈。

## 核心目标

- 建立“标准示范 -> 跟读练习 -> 发音评测 -> 错误诊断 -> 可视化纠错 -> 个性化训练”的学习闭环。
- 利用语音评测接口分析儿童发音准确度，并定位具体错误音素。
- 将错误音素和标准发音动作关联到口型、舌位和发音规则。
- 通过数字人动画、口型示意和舌位展示提升纠错反馈的直观性。
- 根据历史练习记录生成针对性的复习内容和训练计划。

## 当前实现状态

当前仓库实现的是 Android 客户端演示原型，主要用于跑通页面结构和核心交互流程。

已完成内容：

- Android 项目骨架搭建。
- Kotlin + Jetpack Compose 页面开发基础。
- 首页、单词列表、跟读练习、发音结果、学习记录、个人页等页面原型。
- 基于 Navigation Compose 的页面路由串联。
- 示例单词数据和本地演示学习记录。
- 使用系统 TextToSpeech 播放英语标准发音。
- 麦克风权限申请、16kHz/16bit/单声道 WAV 录音、本地保存和回放。
- 语音识别与发音评测服务接口，提交后按“识别 → 评测”顺序执行。
- 离线模拟评分流程，包含准确度、流利度、完整度和错误音素。
- `/θ/`、`/ð/`、`/æ/`、`/ʃ/`、`/r/`、`/l/` 的口型与舌位纠错提示。
- 使用 SharedPreferences 持久化练习结果和录音路径。

暂未接入内容：

- 真实语音识别服务，当前只校验音频格式并返回离线演示文本。
- ISE 或其他语音评测接口。
- 真实音素级错误诊断算法，当前结果由本地稳定规则生成。
- 3D 数字人口型动画，当前提供二维舌位示意。
- 大模型个性化训练推荐。
- Room 数据库与用户账号体系。


## 功能模块规划

### 1. 儿童发音资源库

整理儿童英语学习中常见的元音、辅音和易混淆音素，建立音素、发音规则、口型动作和舌位位置之间的映射关系，为后续诊断和可视化纠错提供基础数据。

### 2. 发音评测与错误诊断

通过移动端采集用户跟读音频，调用语音评测服务获取发音准确度、流利度、完整度等指标，并进一步定位错误音素，生成有针对性的纠错提示。

### 3. 数字人口型与舌位可视化

根据评测结果展示标准口型、舌位动作和发音器官变化过程。当用户把某个音素读错时，系统能够动态演示正确发音方式，帮助儿童理解“舌头放在哪里、嘴巴怎么张、气流怎么走”。

### 4. 个性化训练推荐

基于用户历史练习记录、错误音素分布和学习进度，生成阶段性训练计划、复习单词和跟读句子，帮助用户持续强化薄弱发音点。

## 技术路线

项目整体采用“Android 客户端 + 语音评测服务 + 数字人可视化模块 + 大模型训练推荐模块”的架构。

- Android 客户端：负责页面展示、标准发音播放、录音采集、练习流程、结果反馈和学习记录管理。
- 语音评测服务：负责对用户音频进行发音评分和音素级错误定位。
- 数字人可视化模块：负责根据目标音素展示口型、舌位和发音动作。
- 大模型推荐模块：负责根据历史数据生成个性化纠音建议和训练计划。

## 运行方式

1. 使用 Android Studio 打开项目根目录。
2. 等待 Gradle 同步完成。
3. 选择 Android 模拟器或真机设备。
4. 运行 `app` 模块。

也可以在命令行执行：

```bash
./gradlew assembleDebug
```

Windows 环境可执行：

```bat
gradlew.bat assembleDebug
```
