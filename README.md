# SpeakPal

SpeakPal 是一款面向儿童英语发音学习的 Android 应用，核心目标是把英语发音过程可视化，让孩子能更直观地理解口型和舌位变化，并通过评测反馈帮助纠正发音错误。

## 项目简介

本项目结合语音录音、发音评测、口型与舌位可视化展示、学习记录管理等功能，构建一个适合儿童使用的英语发音练习系统。系统强调“听标准音、看发音动作、跟读练习、获取反馈、再次训练”的闭环学习体验。

## 主要功能

- 首页引导
- 单词选择
- 跟读练习
- 发音结果反馈
- 学习记录查看

## 技术栈

- Kotlin
- Jetpack Compose
- Jetpack Navigation
- AndroidX Material 3

## 项目目标

- 提供适合儿童的发音训练流程
- 可视化展示标准口型和舌位动作
- 给出清晰直观的纠错提示
- 记录练习数据与学习进度
